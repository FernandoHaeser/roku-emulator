# Changelog

## 0.1.0 (preview)

- Embedded emulator panel backed by a runtime in a Node Worker.
- Start, stop, restart, configure project, select runtime and open in browser
  commands.
- `roku-emulator` debug type over the binary debug protocol: breakpoints, hit
  counts, stepping, threads, stack, variables, watches and set variable.
- Network through a local proxy (`roUrlTransfer`, cookies, Digest).
